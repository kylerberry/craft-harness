# CRAFT Lite Adapter

Before execution, read the sibling [`../craft/SKILL.md`](../craft/SKILL.md) completely. This file defines only the entry condition and overrides; `/craft` owns every other phase, counsel, reporting, and escalation contract — including the R-exit simplify pass, which the conductor performs directly, not by spawning an agent.

Use `/craft-lite` when a full counsel review of the plan and Tighten are out of scope (prototype, spike, or the user says skip T). Use `/craft` when the full `C → counsel → R → A → [F] → T → S` path is required. Use `/craft-hitl` when Render must pause at a `TODO(human)` seam.

## Flow

`C → R → A → [F] → S`

There is no counsel review of the plan generated by C. Do not spawn `craft-counsel`.

There is no T. Do not spawn `craft-security-review`. Do not emit a T metrics phase.

`craft-metrics enter --phase counsel` and `--phase T` are rejected by the store when the run's mode is `lite` (nonzero exit, no event written). This is a hard backstop, not a suggestion: if you hit that error, you attempted a phase this protocol forbids — stop, do not spawn the agent, and continue the flow without it. Do not work around the rejection by skipping the metrics call and spawning the agent anyway.

Render, including the required simplify exit gate, is unchanged from `/craft`.

### S — Sharpen without T

Pass an empty T non-P0 list. S still records durable docs and process notes. Do not use S to backfill a security review.

## Metrics

Start with `--mode lite` and the same `--kind` rules as `/craft`. Skip T `enter`/`exit`. All other gates emit as in `/craft`.
